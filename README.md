# Ayyappa Swamy Thati — portfolio

A static portfolio for GitHub Pages. The page is generated by a small Rust program using only the standard library; visitors receive HTML, CSS and a little JavaScript, not a WebAssembly runtime.

## Edit and build

Edit `content/projects.tsv` (eight tab-separated fields: number, category, eyebrow, title, description, technologies, URL and link label) or `src/template.html`. From the repository root run:

```sh
rustc --edition=2021 src/main.rs -o /tmp/portfolio-build
/tmp/portfolio-build
python3 tests/site_check.py
```

Commit the generated `index.html` along with the source so GitHub Pages can publish it directly. Styling and filtering live in `assets/css/style.css` and `assets/js/main.js`. The project list remains visible without JavaScript.
